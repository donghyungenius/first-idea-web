# 🌟 오늘도 힘내세요! (Daily Cheer)

화면 중앙에서 따뜻하고 힘이 되는 영감 문구들을 전해주는 반응형 인터랙티브 웹페이지입니다.

---

## ✨ 주요 기능
- **4가지 응원 문구 순환**: '다음 문장 보기' 버튼 클릭 시 4가지 영감 문구로 부드럽게 페이드 전환
- **동적 버튼 컬러 테마**: 각 문장에 맞춰 버튼 색상이 파랑, 노랑, 주황, 초록으로 유기적 전환
- **3D 입체 틸트 효과**: 마우스 커서 이동에 반응하는 3차원 글래스모피즘 카드 인터랙션
- **모던 에디토리얼 디자인**: 밝은 회색 그라데이션과 프로스티드 글래스(Frosted Glass) 테마

---

## 🛠️ 기술 스택
- **Markup & Styling**: HTML5, Vanilla CSS3 (Pretendard & Plus Jakarta Sans)
- **Interactive Logic**: Vanilla JavaScript (ES6+)
- **Responsive**: Fluid clamp typography & responsive layout
